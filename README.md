# PIXEL FORGE v3.9

日本語中心のブラウザ向けドット絵エディターです。GitHub Pages などの静的ホスティングに配置できます。

## v3.9 ロゴ更新
- ロゴを白一色・透過背景のピクセルアートシンボルに変更。
- ヘッダーの白いタイル背景と枠線を取り除き、ダークな画面に直接表示。
- ファビコン、iPadホーム画面用アイコン、Web App Manifestを更新。
- `assets/pixel-forge-logo-white.png` に白色・透過背景のロゴ全体を収録。

## 主な機能
- ペン、消しゴム、塗りつぶし、色取得、図形、選択、移動、模様塗り
- レイヤー管理、取り消し・やり直し、自動保存
- 画像のドット化、参照画像との比較、対称描画、フィルター
- 最大500×500pxのキャンバス、複数形式の書き出し
- 作業画面専用の拡大表示（ブラウザ全体の全画面表示とは別）

## 公開方法
`index.html`、`manifest.webmanifest`、`assets` フォルダをまとめて同じ公開ディレクトリにアップロードしてください。assetsフォルダを省略するとロゴやホーム画面アイコンが表示されません。

## iPadホーム画面
Safariで公開サイトを開き、「共有」→「ホーム画面に追加」を選びます。古いアイコンが残る場合は、ホーム画面から旧アイコンを削除して再追加してください。
