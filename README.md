# PIXEL FORGE v3.1 — ドットアート工房

ブラウザだけで使えるドット絵制作ツールです。画像は基本的に端末内で処理されます。

## 起動方法
- `index.html` を対応ブラウザで開いてください。
- GitHub Pages などの静的ホスティングにも配置できます。

## 主な機能
- ペン、消しゴム、塗りつぶし、色取得、直線、四角形、楕円、範囲選択、移動、模様塗り
- レイヤー追加・複製・表示切替・並べ替え・結合・編集ロック
- 画像を指定ピクセル数にドット化、色数制限、ディザリング
- ドット化時の元画像の縦横比維持（初期状態で有効）
- お手本画像との左右比較と、編集画面上への半透明オーバーレイ
- ツールボックス／制作パネルの折りたたみ、上部クイックツールバー
- キャンバス反転・回転、対称描画、色置換、色数削減、パレット読み込み
- 元に戻す／やり直し、自動保存、PNG・WebP・JPEG・SVG・BMP・JSON・CSS・TXT出力

## 補足
- ピクセル数の比率は整数ピクセルに合わせて丸められるため、元画像の縦横比は可能な限り近似して維持されます。
- ブラウザの保存領域を消去すると自動保存データも消える場合があります。大切な作品は編集データ（JSON）でも保存してください。


## v3.2 追加改善
- 編集画面上部に常時表示のクイックカラーパレットを追加。基本色・登録色の選択、現在色の登録に対応。
- 左右のパネルは独立してスクロールし、キャンバスは作業領域の上端に固定して配置。
- お手本画像をクリックして色を取得し、その色を登録パレットに追加。
- ロック表示などの絵文字を非絵文字記号に変更。
