# PIXEL FORGE v2
ドットアート制作サイト。`index.html` をブラウザで開くか、GitHub Pagesのリポジトリに配置してください。

## 追加機能
- レイヤー追加・複製・表示切替・並べ替え・名前変更・削除・下レイヤーへ統合
- 選択範囲の作成と範囲の移動
- 選択範囲／レイヤー全体のクリア
- HEX指定による色の一括置換（透明化も可能）
- 使用頻度ベースの色数削減と近似色統合
- チェッカー、ドット、斜線、クロスのパターン塗り
- GIMP GPL、HEXリスト、JSONパレットのインポート
- Pointer Eventsによるマウス／タッチ／スタイラス操作
- PNG倍率書き出し、SVG、編集可能なJSON
- 自動保存、Undo/Redo、左右・上下対称、グリッド、画像インポート
## 注意
色数削減は選択中レイヤーの使用色を頻度に基づいてまとめる簡易方式です。スタイラスの筆圧強弱による不透明度は実装していませんが、タッチ・ペン入力はPointer Events経由で対応します。
