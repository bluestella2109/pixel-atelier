# PIXEL FORGE v3.3

ブラウザで動作する日本語対応のドット絵エディターです。

## v3.3 の追加機能
- フィルター：モノクロ、セピア、レトロ、ウォーム、クール、ビビッド、ハイコントラスト、色あせ、ネガポジ反転、新聞印刷風
- iPad・スマートフォン：編集画面上で二本指をピンチして拡大・縮小、二本指を動かして表示位置を移動
- パソコン：編集画面上で右クリック＋ドラッグして表示位置を移動
- Ctrl / Command + マウスホイールでズーム
- PNG / WebP / JPEG などのラスター書き出しでは、選択したフィルターを反映

## 起動方法
`index.html` を最新のブラウザで開くか、GitHub Pages などの静的ホスティングに配置してください。

## 操作
- 拡大・縮小：編集画面上部の「＋」「−」、または対応端末のジェスチャー
- 表示位置の移動：タッチ端末は二本指ドラッグ、パソコンは右クリック＋ドラッグ
- フィルター：編集画面上部の「フィルター」メニュー

画像処理は基本的にブラウザ内で実行されます。
