# PIXEL FORGE v3.4

日本語中心のブラウザ向けドット絵エディターです。`index.html` をブラウザで開くか、GitHub Pages に配置して利用できます。

## v3.4 の更新
- キャンバス幅・高さの上限を 500 × 500 px に拡張
- 画像のドット化も最大 500 px、縦横比維持に対応
- フィルター効果の強さを 0〜100% で調整
- 左右対称・上下対称の描画中にシアンのガイド軸を表示
- ペン、消しゴム、塗りつぶし、色取得、図形などのツールアイコンを、拡大縮小しても鮮明な線画SVGに統一

## 主な機能
- ペン、消しゴム、塗りつぶし、色取得、直線、四角形、楕円、範囲選択、移動、模様塗り
- レイヤー管理、表示切替、ロック、並べ替え、複製、結合
- お手本画像との比較、半透明オーバーレイ、お手本からの色取得
- ピンチズーム、2本指パン、PCの右クリックドラッグ
- PNG、WebP、JPEG、SVG、BMP、JSON、CSS、TXT 書き出し
- 自動保存、取り消し、やり直し、パレット読み込み

画像処理は基本的にブラウザ内で行います。500 × 500 px など大きなキャンバスでは、端末の性能によって操作が重くなる場合があります。
