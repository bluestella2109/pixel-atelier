# PIXEL ATELIER

ブラウザだけで使えるドットアート制作サイトです。サーバーやビルド手順は不要です。

## 起動
`index.html` をブラウザで開いてください。GitHub Pagesに公開する場合は、このファイルをリポジトリのルートに置いてください。

## 主な機能
- 8〜128pxのキャンバスサイズ設定
- ペン、消しゴム、塗りつぶし、スポイト、直線、四角形、楕円
- 左右・上下対称描画、グリッド、透明背景
- 複数カラーパレット、カスタムカラー追加
- Undo / Redo、最大80段階の編集履歴
- PNG（倍率指定）、SVG、編集用JSONの書き出し
- 画像の読み込みとピクセル化、JSON編集データの再読み込み
- ブラウザ内の自動保存
- キーボードショートカット：B / E / G / I、Ctrl+Z / Ctrl+Y

すべての作品データはブラウザ内で処理され、外部サーバーへ送信されません。
